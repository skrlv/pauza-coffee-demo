# Пауза — кофе и немного времени

Второй демонстрационный проект для портфолио: русскоязычный сайт вымышленной кофейни с меню, поиском, фильтрами, карточками состава и избранным. Меню, цены и бренд условные. Сайт не оформляет заказы, не принимает оплату и не собирает контактные данные.

Публикация: [GitHub Pages](https://skrlv.github.io/pauza-coffee-demo/). Исходники: [skrlv/pauza-coffee-demo](https://github.com/skrlv/pauza-coffee-demo). После успешного workflow сайт работает независимо от локального компьютера.

## Возможности

- 12 позиций: кофе, чай и какао, десерты.
- Поиск по названию, описанию, составу и тегам, с учётом регистра и ё/е.
- Категории, сортировка цены и фильтр избранного работают совместно.
- Карточка продукта показывает описание, условные цену/объём и состав. Диалог закрывается по кнопке, Escape и нажатию снаружи; фокус возвращается к исходной кнопке либо заголовку меню.
- Избранное сохраняется только в localStorage этого браузера. Изменения синхронизируются между вкладками.
- Недоступное хранилище показывает предупреждение: выбор временно остаётся в памяти вкладки. При восстановлении доступа временные добавления и удаления объединяются с сохранённым списком.
- Повреждённое избранное не перезаписывается автоматически. Для сброса нужен отдельный шаг подтверждения; другие данные браузера не удаляются.
- Адаптивная версия, подписи элементов, клавиатурный фокус и поддержка уменьшенного движения.

## Локальный запуск

Нужен Node.js 22.18 или новее и npm. При первой установке зависимостей нужен интернет; фотографии, шрифты и иконки затем доступны из самого проекта.

```sh
npm ci
npm run dev
```

Откройте [локальный сайт](http://127.0.0.1:3010/). Для статической версии с тем же путём, что у GitHub Pages:

```sh
npm run build:pages
npm run check:pages
npm run preview:pages
```

Откройте [статический просмотр](http://127.0.0.1:4174/pauza-coffee-demo/). Команда `Ctrl+C` останавливает локальный сервер. Результат сборки — папка `out/`; её можно размещать на статическом хостинге.

## GitHub Pages

Workflow `.github/workflows/pages.yml` устанавливает зависимости, запускает тесты, собирает сайт, проверяет ссылки и публикует результат после push в `main`. В Settings → Pages должен быть выбран источник **GitHub Actions**. Собственный сервер, платная подписка и секретные ключи не нужны для этой демонстрации в публичном репозитории.

`build:pages` определяет путь по `GITHUB_REPOSITORY`: `/имя-репозитория` для проекта и пустой путь для `owner.github.io`. Локально используется `/pauza-coffee-demo`. Значение можно переопределить через `NEXT_PUBLIC_BASE_PATH`; при локальном просмотре задайте серверу тот же путь. Обычный `npm run build` без этой переменной создаёт статическую сборку для корня домена.

GitHub Pages подходит для показа портфолио. Для настоящих заказов, оплаты, общей базы или авторизации нужна отдельная серверная часть; на этом сайте их нет.

## Данные и изменения

| Файл                         | Назначение                                                     |
| ---------------------------- | -------------------------------------------------------------- |
| `lib/menu.ts`                | Позиции, цены, категории, состав, фильтрация и сортировка.     |
| `lib/favorites.ts`           | Проверка, сохранение, восстановление и объединение избранного. |
| `lib/paths.ts`               | Префикс пути для ресурсов GitHub Pages.                        |
| `components/coffee-site.tsx` | Страница, поиск, карточки, диалог и состояния интерфейса.      |
| `components/icons.tsx`       | Собственные SVG-иконки.                                        |
| `app/globals.css`            | Цвета, типографика, адаптивность и доступные состояния.        |
| `public/images/`             | Локальные фотографии.                                          |
| `ASSETS.md`                  | Источники фотографий и лицензия.                               |

Ключ избранного: `pauza.favorites.v1`. Формат: `{ "version": 1, "favorites": ["latte"] }`. Сохраняются только известные идентификаторы позиций; дубликаты и удалённые из меню позиции отбрасываются. Личные данные не запрашиваются и не сохраняются. Разные браузеры и origin имеют независимые списки.

## Проверки

```sh
npm test
npm run typecheck
npm run build:pages
npm run check:pages
```

Тесты используют встроенный модуль Node.js: проверяют поиск, совместные фильтры, сортировку, чистоту операций, версию данных, сохранение/восстановление, повреждённое/недоступное хранилище и восстановление временных изменений. Проверка экспорта находит отсутствующие ресурсы и неправильные префиксы ссылок.

Фотографии иллюстрируют позиции, а не точную рецептуру или реальное помещение бренда. Источники и условия использования указаны в [ASSETS.md](ASSETS.md).

### Обновлённый интерфейс

Главная страница оформлена как кофейная афиша: заголовок отделён от фотографии. На телефоне меню стало одноколоночным, с более крупным текстом и кнопками. Добавлены появления разделов, плавный отклик карточек, сердечек и диалогов; уменьшенное движение учитывается. Мобильное меню закрывается по Escape и после перехода.
